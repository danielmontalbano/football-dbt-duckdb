# Data attribution

This project uses the **SkillCorner Open Data** release:
<https://github.com/SkillCorner/opendata> (MIT licence).

Twenty 2024/25 Australian A-League matches of broadcast tracking data and the
derived Dynamic Events, open-sourced by SkillCorner. If you build on this,
credit SkillCorner.

Column definitions come from *Dynamic Events CSV Specifications* (2025-02-16),
published by SkillCorner.

No provider data is stored in this repository: it is downloaded to your
machine when you run the ingestion script. The pipeline code is independent
of, and not endorsed by, SkillCorner.
